# DNS 路径性能优化与安全边界

本轮只优化 fork 新增的 DNS 规则路由、原生 DNS 缓存/候选处理和 DIRECT 探测路径。普通代理连接仍使用原来的匹配与转发逻辑，关闭 `dns-rule-routing` 不使用 DNS 派生规则视图或专用 ARC。共享模块只新增按需日志辅助方法，不改变原有日志订阅接口。

## 规则执行

配置加载时由同一份 rules 生成 DNS 执行视图。逻辑端口为 53，目标网站 IP 未知；已知来源、端口、进程、入站条件保持真实语义和原始顺序。AND / OR / NOT 保留三值逻辑、短路顺序和动态 wrapper 的统计/禁用行为。RULE-SET 的 src 交换及不能证明等价的条件回到旧求值器。

classical provider 的不可变策略快照可建立派生索引：仅连续的普通小写 ASCII DOMAIN / DOMAIN-SUFFIX 段达到阈值时转换为现有 DomainSet。关键词、正则、复杂逻辑、来源、进程、wrapper 留在原位置。新 provider 快照不复用旧索引。派生视图数量有界，缓存的是匹配结构，不是最终出口。

## 应答复用与取消

每个请求先匹配当前完整规则并处理拒绝，再构造结构化缓存身份，不再 JSON 序列化全部元数据。仅当路由成功、所选上游全部自动时，允许同一真实来源 IP、进程、认证、入站和规则作用域的查询跨临时源端口复用回答。实际出口、上游池、模式世代和完整查询内容仍进入身份；ID 除外，DO / CD、ECS、Cookie 等保留。

本轮没有无条件合并不同客户端 IP 的应答，也没有缓存“域名到出口”的长期决定。源端口依然参与当前规则；它导致出口不同就产生不同缓存。未在途的应答可以复用，在途 DNS singleflight 仍保持源端口隔离，避免用户取消一条查询时取消别人的查询。后台刷新保存自己的来源/进程快照并重跑规则，不能因端口被其他进程复用而冒认身份。

原生自动 DNS 的实际未命中工作最多同时 256 条；超限明确失败，不建立无界等待队列，不转成 DIRECT。缓存命中、基础解析和普通业务转发不受这个新增工作额度限制。

## DIRECT 探测和双栈

每个共享 checker 惰性启动固定数量工作者，新 IP 探测先尝试原子取得活动名额；名额满立即跳过，不进入等待名额的队列，也不限制上游 DNS 请求的并发。相同实际 DIRECT 出口、接口/mark 等出站策略与 DSCP 下的同目标 IP 可合并探测；探测方式属于 checker 的不可变配置。仅成功 RTT 在最多 1024 项环形历史里保留 1 秒。所有等待者有独立取消语义；最后一个等待者离开才取消该探测。已有共享任务的生命周期仍由首个请求的预算决定，本轮未重做该调度策略。超载只跳过优选，已有有效 DNS 回答仍可以返回，不把未探测成功当作域名不存在。

双栈原始候选回答另有最多 1024 条、最长 1 秒的短期复用；身份包含真实上游实例、包装设置、所选上游集合、来源作用域及查询内容，不会把 main/fallback 相同下标当作同一上游。复用不超过原答案 TTL；包含 OPT/EDNS 或签名保护的事务保守跳过候选缓存，仍正常返回本次上游答复。正在进行的候选交换不跨请求合并，以保持取消与面板关闭的原行为。重用探测结果同样要记录到每个查询的双栈测量中；不能只在实际执行套接字探测的第一个调用者上记录。

代理路径永远不执行这些本地探测。带 DNSSEC 保护的答案继续按现有保护逻辑处理。speed-check-timeout 限制可选优选等待；到期已有合格答复就返回，尚无 DNS 答复则停止测速、继续等待已经发出的同一批上游，服从原解析期限，不重复发起整批 DNS。main 完整回答先执行原版 fallback 过滤，随后才允许缩窄 RRset；被禁用的 IPv6 回答不能参与抑制 IPv4。等待时间计入原答复的 TTL，不在测速结束后重新获得完整缓存寿命。

## 高频开销与生命周期

DNS 调试日志只有控制台或日志订阅者需要时才生成复杂文本；原日志 API 不变。DNS 专用 ARC 只改同链表 MRU 原位移动，原 common/arc 不动。缓存消息复制、TTL/OPT 处理在世代控制锁外准备，最终写入在锁内再次核对世代。清空、重载和关闭不能让旧任务回填；共享探测与候选缓存随 resolver 关闭释放。

## 验证方法

- 原有协议、加密 DNS、来源/进程/入站、逻辑规则、切组、取消、重载和 DNSSEC 回归。
- `TestDNSPerf`：跨源端口应答复用但在途独立；认证/进程隔离；编译视图与旧求值器对照；classical 更新；共享探测、取消、容量、关闭；共享 RTT 的双栈结果；候选世代与不可变性；ARC 命中零额外节点分配。
- `scripts/test-dns-perf.py <binary> --expect-shared`：只访问本地受控上游，50 个不同回环来源、每次换端口，验证热缓存复用、DIRECT/代理选池、来源优先和拒绝；代理答案 IP 不出现本地探测。
- 同一受控脚本运行旧版作对照。旧版在压力阶段的超时/SERVFAIL单独记录，不伪装成成功；错误出口、错误回答、拒绝漏查和代理探测始终是失败。
- 基准、吞吐与延迟只在测试日志输出，不增加成品指标接口、常驻采集器或遥测。

结果只代表对应提交、运行器和受控负载，不等同于用户网络的带宽或全部设备上的极限性能。发布以最终提交的完整 CI 和 37 目标构建结果为准。
