# 配置编辑与面板更新

内核 `v1.19.32-optimized-12` 与面板 `0.3.6` 提供以下功能。面板继续使用现有 `clash-dashboard` 源码及 `clash-dashboard-dist` 静态分支，版本不带额外后缀。

## 编辑当前配置文件

设置页点击“编辑配置”，读取当前内核正在使用的普通 UTF-8 YAML 文件。API 沿用控制器原有鉴权：

| 请求 | 含义 |
| --- | --- |
| `GET /configs/file` | 返回 `path`、`content`、`revision`、`max_size` |
| `PUT /configs/file` | JSON 提交 `content` 和读取时的 `revision`，保存后返回新的文件及修订标识 |

**保存文件与应用配置分开。** 保存检查单个 YAML 映射及基础字段类型，不调用运行态配置解析或应用，也不下载 providers。保存后通过原有“重新加载配置”执行完整校验和应用；读取与保存本身不会清 DNS 缓存、重置观测或中断连接。

不接受任意文件路径。当前配置超过 4 MiB、使用 AGE 加密、非 UTF-8、文件不是普通文件或路径中包含符号链接时，编辑器显示相应限制。嵌入模式禁用该接口。草稿和修订标识仅保留在页面内存，关闭或切换控制器即释放；服务端响应包含 `Cache-Control: no-store`，错误不回显 YAML 或凭据。

保存请求使用单操作闸门，忙时返回 `503` 而不积压配置缓冲。文件变化后返回 `409`，面板保留草稿；单次写入采用同目录临时文件、同步与替换，并保留原权限和属主。Linux 额外保留 POSIX 访问 ACL，Windows 保留属主、组及 DACL。无法保留这些访问权限时不替换原文件。

文件身份、路径及内容修订在替换前重新检查。编辑器请求之间具有冲突保护；不共享此操作锁的外部程序仍可能在最后检查与文件替换之间写入，不承诺跨进程的文件事务。完整重载与直接修改磁盘文件仍按原有方式使用。

## 跟随 external-ui-url 更新面板

更新使用内核当前生效的 `external-ui` 目录、`external-ui-name` 和 **`external-ui-url`**，不硬编码某个仓库，也不因其他面板缺少本项目的版本元信息而禁止更新。修改这些配置后需要重载使其生效。

`external-ui` 未指定时，手动更新接口沿用原内核的 `<配置主目录>/ui` 默认目标；是否对外提供该目录仍由原有 `external-ui` 配置决定。自动检查不另建更新源或改写这些配置。

| 请求 | 含义 |
| --- | --- |
| `GET /upgrade/ui` | 读取当前面板与已缓存的更新状态，不发起源下载 |
| `GET /upgrade/ui?check=true` | 检查配置的更新源，验证归档并比较文件摘要 |
| `POST /upgrade/ui` | 安装已验证的更新快照；未检查时先检查 |

状态包含 `supported`、`update_available`、`updating`、当前及可用版本/提交、文件摘要和可选的通用错误状态。没有 `build-info.json` 时版本与提交可为空，更新依据实际文件内容；响应不暴露更新 URL、URL 内的凭据或私密参数。

检查使用全局并发控制、5 分钟结果缓存，以及更新源支持时的 ETag / Last-Modified 条件请求。下载、解包、文件数量和总大小受限；下载完成并校验后才替换，失败保留旧面板。检查暂存文件有界保存在面板目录旁，内容只有面板静态资源；DNS 数据和配置草稿不进入这些文件。

单个归档最多 64 MiB，展开后最多 256 MiB、10000 个文件及目录节点，单文件最多 32 MiB，路径深度最多 64 层。只保留上一代静态资源以照顾仍打开的页面，额外保留量同样有界；内部暂存、恢复目录及资源记录不会由 `/ui/` 静态服务提供。更新源或目标目录在重载时改变，会取消旧任务，并在最终替换前再次确认仍是当前配置。

面板自动拉取默认关闭。开启后立即检查，并在页面打开、可见且在线时每 6 小时检查当前控制器；隐藏或离线期间不发起周期请求，恢复后按周期补查。关闭网页后不再运行此浏览器定时任务。内核原有启动时仅在目录为空时下载的行为保留。

**面板更新不重载配置、不重启内核、不清理 DNS 缓存或观测。** 完成后仅提示手动刷新。配置编辑器打开时不刷新，准备刷新期间新打开编辑器也会取消页面刷新；刷新页面本身会重新建立浏览器内的连接、日志和 DNS 视图，内核数据继续保留。

页面由当前内核 `/ui/` 托管时，手动刷新只注销当前 UI 范围内的 service worker，再加载新文件，兼容更换为没有 `sw.js` 的其他面板。不会删除控制器设置、其他应用的 service worker 或缓存。外部站点托管的面板提供“打开内核面板”，更新操作不会修改外部站点。

本面板的安装与前端细节见 [面板 README](https://github.com/chummumm/mihomo-dns-optimized/blob/clash-dashboard/README.md)。
